# Sylvan existing-model generation and value completion — 2026-07-29

## Scope

This pass covers the **16 Sylvan records already present in BoatBuilder**. It does not attempt to add every Sylvan model ever produced. The completion standard for these existing records is:

- no open `unresolved` generation rows
- every recoverable production year checked through available factory archives and annual model records
- materially different annual specifications separated instead of blended
- each physical generation or annual variation assigned a defensible used complete-package screening range
- seller shorthand and family umbrellas closed as non-model dispositions rather than priced as boats

## Result

- **16 existing Sylvan records reviewed**
- **39 physical generations or annual variations represented**
- **0 unresolved Sylvan generation rows remain**
- **39 of 39 physical generations have used-package value ranges**
- **2 non-model rows remain intentionally unpriced:** `Fish and Ski` and `Viper`
- Some older annual records expose only the fields actually recovered. They are marked source-exhausted rather than borrowing the nearest catalog's complete specifications.

## Used-value method

These are practical screening ranges for a **complete running boat, outboard and ordinary trailer**, not bare-hull book values. The ranges use a limited evidence set rather than pretending that every variation has a large current sales sample:

1. surviving exact-model advertisements and sold-listing archives
2. J.D. Power/NADA hull values as a lower structural anchor
3. expected motor and trailer value for the model year and horsepower class
4. adjustments for kickers, canvas, electronics, downriggers, unusual low hours and documented rebuilds

Examples used to calibrate the upper ends include a low-hour 2011 Expedition Sport 1800 package advertised around $21,000, a 2004 Explorer 1600 DC package around $10,995, and a heavily equipped 1999 Pro Select 1700 package advertised at $10,500. Asking prices are evidence of market positioning, not proof of transaction price, so BoatBuilder retains broad ranges.

## Remaining limitations

Several 1980s and 1990s factory PDFs are image-heavy or no longer expose searchable annual specification tables. Where the annual roster establishes the model, year and a changed published weight but the remaining table cannot be recovered, BoatBuilder records a **source-exhausted partial variation**. Those rows are closed because the available official archive and secondary annual records were exhausted, but they do not invent beam, capacity or gauge values from an adjacent year.

This is complete for the Sylvan models currently in BoatBuilder. It is not a complete roster of every Sylvan model ever manufactured.
