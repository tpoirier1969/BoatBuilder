# Generated audit reports

These files are generated from the canonical JavaScript catalog by `scripts/report-unfinished.mjs`.

- `unfinished-work.md` is the human-readable manufacturer backlog.
- `unfinished-work.json` is the machine-readable unresolved-generation inventory.
- `smoker-craft-current.json` captures the current Smoker Craft records used by the focused audit.

Do not hand-edit generated report files. Update canonical catalog data or the reporter and regenerate them.
